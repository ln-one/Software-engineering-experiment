## 文档规范

### 编号规则
- 文档编号格式：[项目代码]-[文档类型]-[版本号]
- 章节编号：采用层次化编号（1, 1.1, 1.1.1）
- 图表编号：全局统一编号（图1, 表1）

### 命名规范
- 文件名：中文名称.md
- 变量名：驼峰命名法
- 数据库表名：小写字母+下划线
- 接口名：RESTful风格

- 版本号格式：V主版本号.次版本号
- 重大变更：增加主版本号
- 小修改：增加次版本号
- 版本历史：记录在文档开头
